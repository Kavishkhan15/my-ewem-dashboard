# Premium UI and Art Direction

1. Read `DESIGN.md` before creating UI components; derive a tokenized dark/light palette and type hierarchy.
2. Use the signature **environmental research observatory / premium editorial instrument** art direction; don't clone the friend's Fraunces hero or generic administration templates.
3. Define and test reusable components with keyboard interactions and default/hover/focus/disabled/loading/empty/error/success states.
4. Make the Command Center instantly explain: 14 tracked records, 13 observed badges, actual completion unknown, prioritized review queue. Avoid giant fake dashboards.
5. Create meaningful visual storytelling: category comparison from real 4/3/4/2/1 counts, chronological timeline from actual dated entries, evidence links and honest research placeholders.
6. Test 320px, 390px, 768px, 1280px, 1440px; light/dark, pointer/keyboard, reduced-motion, readable typography and color contrast.
7. Use actual browser screenshots and iterative visual critique. Assign at least one independent reviewer to identify genericness, spacing issues and unresponsive layouts.
8. Don't treat screenshots as functional proof: controls must be wired, persisted and tested.
