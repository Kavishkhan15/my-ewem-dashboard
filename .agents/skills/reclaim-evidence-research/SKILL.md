# Evidence and Research Integrity

1. Do not fabricate datasets, carbon emissions, recycling yields, India/world e-waste metrics, policy compliance conclusions, company names, LEED building certifications or assignment grades.
2. Data becomes chartable only after explicit user upload or trustworthy sourced retrieval; record source URL/document, period, geography, method, unit and transformations.
3. Preserve raw uploaded files and dataset version lineage; distinguish user upload, published source, derived calculation and unverified assertion.
4. Security-first import: check size, extension and actual format where feasible; avoid executable HTML and unsafe inline preview. Preview supported PDF/images/text within sandboxed viewers; use download fallback for unsupported types. No external processing/upload without consent.
5. Charts must include a table alternative, accessible labels and provenance; explain limitations and uncertainty, especially when comparing regions or years.
6. Showcase release is manual and explicit; private notes and unpublished artifacts remain private.
7. Verification: upload, refresh, download, delete recoverability, malformed import, oversized files, unsupported formats and privacy leak tests.
