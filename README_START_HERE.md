# RECLAIM MAGNUM — Start Here (Antigravity CLI)

This is a **repository instruction pack and implementation request**, not a pre-built application. It was prepared from the 14-assignment EW/EM discussion and the user's friend-portfolio reference. The actual website must be built and tested by Antigravity CLI on the user's computer.

## Correct folder layout

```text
RECLAIM/
├── AGENTS.md                          # auto-discovered repository rules
├── AGENT.md                           # human-readable lead persona source
├── SKILL.md                           # portable root copy of the skill
├── DESIGN.md                          # UI/UX guardrails (explicitly read by agents)
├── FINAL_ANTIGRAVITY_PROMPT.md        # full copy-paste execution prompt
├── README_START_HERE.md
├── .agents/
│   ├── agents/
│   │   ├── reclaim-orchestrator/agent.md   # lead orchestrator
│   │   └── ...19 specialist agent folders # 20 definitions total
│   └── skills/
│       ├── reclaim-delivery/SKILL.md     # lead delivery workflow
│       └── ...5 focused skill folders    # 6 skills total
├── data/
│   └── assignments.seed.json          # exactly 14 validated records
├── references/
│   ├── PROJECT_BRIEF.md               # all product requirements
│   └── Index.html                     # OPTIONAL: add privately; not included
├── scripts/verify_magnum_pack.py      # validates files/seed, not runtime agents
└── docs/                               # QA/report templates; final reports generated by Antigravity
```

**Important discovery note:** Current Antigravity CLI documentation automatically discovers repository `AGENTS.md`, workspace custom agents under `.agents/agents/<name>/agent.md`, and skills under `.agents/skills/<name>/SKILL.md`. A bare root `AGENT.md`, `SKILL.md`, and `DESIGN.md` are **not sufficient by themselves** to register the agent/skill or auto-apply design rules. This kit includes working copies at recognized locations and explicitly references `DESIGN.md` from `AGENTS.md`.

## Quick launch

1. Extract the ZIP into a **private project directory** named `RECLAIM` (or merge the contents into an existing project). Make sure `AGENTS.md` is at the repository root.
2. If you want Antigravity to inspect your friend's reference, manually place its `Index.html` under `references/`. This file contains another student's personal information and submitted coursework. Keep it untracked/unpublished and **never** put it under `public/`.
3. Open Terminal in the repository root and type:

   ```bash
   agy
   ```

   If unavailable, consult official Antigravity CLI installation docs and verify `agy --version`. Do not install from random third-party scripts.
4. If your plan supports Antigravity's native multi-agent teamwork mode, use the **single-line kickoff** inside the CLI prompt:

   ```text
   /teamwork-preview Read AGENTS.md, AGENT.md, DESIGN.md, .agents/skills/reclaim-delivery/SKILL.md, references/PROJECT_BRIEF.md, data/assignments.seed.json and FINAL_ANTIGRAVITY_PROMPT.md. Execute the RECLAIM MAGNUM mission end-to-end using native Antigravity CLI teamwork, targeting 15–20 truly parallel specialists where supported, discovering and using relevant authorized MCPs and skills, then build, integrate, browser-test, secure, polish and document the real 14-assignment application. Honor the user's explicit approval gates and report actual team count and test evidence. Do not stop at planning.
   ```

   Teamwork may conduct a **mandatory scoping interview and approval** first; review and approve its artifact to begin autonomous execution. The 15–20 concurrency request is not guaranteed by the product and must be verified, not assumed.
5. If `/teamwork-preview` is unavailable, select `reclaim-orchestrator` in `/agents` if it is shown, then paste the **full contents** of `FINAL_ANTIGRAVITY_PROMPT.md` in the regular Antigravity CLI prompt pane.
6. Use `/mcp` to inspect connected MCP servers. Registered local/global skills may also be inspected through available Antigravity skill interfaces. **Do not install/grant all possible MCPs indiscriminately.** The brief calls for every **relevant and authorized** tool.
7. When it finishes, run the documented install/dev/build/test commands locally, inspect desktop and mobile screenshots, and review `docs/TEST_REPORT.md` and `docs/AGENT_LEDGER.md`. Only actual tests and working functionality count.

## What is and is not included

**Included:** 4 requested root files, a full execution prompt, **20 discoverable custom agent definitions (including the lead)**, **6 discoverable focused skills**, an authoritative product brief, truthful machine-readable 14-item seed, QA/capability templates, a standard-library pack verifier, and instructions.

**Not included:** a finished web application, 15–20 already-spawned agents, connected MCP servers, faculty grades, coursework files, new external credentials, or your friend's reference HTML. These must be supplied or executed inside your own Antigravity environment.

## Privacy and backups

Keep `references/Index.html` out of your public repository. If using git, add it to `.gitignore`. Local-first storage lives in the browser, so export backups before clearing data; server/cloud persistence requires separate authorized setup. Do not publish private coursework without explicit action.

## Verify this pack before the Antigravity run

From inside the extracted project folder, run `python scripts/verify_magnum_pack.py` (or `py scripts\verify_magnum_pack.py` on Windows). This checks repository files and seed invariants, **not** runtime agent activation. Then run `agy --version` and `agy` from the project folder; use `/agents`, `/skills`, `/mcp` for *actual* discovery. The package defines 20 specialized custom agents and six skills, but does not launch them by itself.

The root `AGENT.md` and `SKILL.md` are portability copies. Antigravity's registered definitions are in `.agents/agents/` and `.agents/skills/`. The `DESIGN.md` is explicitly read under `AGENTS.md`. The provided `docs/*_TEMPLATE.md` files are blank tracking forms; outcomes must be populated by real work.
